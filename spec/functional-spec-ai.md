# EE041 电子档案对接报表（ZSAP_FI250）

## 业务目标与报表类型

- 报表类型：在线 ALV 明细报表
- 目标：按电子档案规范抽取 FI 凭证与行项目数据，供电子档案底表对接
- 执行频度：日

## 选择条件

| 选择项 | 类型 | 必输 | 表.字段 |
|---|---|---|---|
| 公司代码 | 多选 | 是 | BKPF.BUKRS |
| 会计年度 | 单选 | 是 | BKPF.GJAHR |
| 期间 | 单选 | 是 | BKPF.MONAT |

> FS 中 BKFP 为笔误，统一修正为 BKPF。

## 输出列（核心）

- 档号（默认 `EEKA`）
- 机构代码、机构名称、分公司代码、分公司名称
- 会计年度、会计期间、过账日期、记账日期、修改日期
- 凭证类型、凭证号码、凭证字、摘要、序号
- 会计科目编码/描述、币别、原币金额、借方金额、贷方金额
- 部门/部门名称、利润中心/利润中心描述、行项目文本
- 客户/供应商/物料/资产相关名称字段（按 FS 规则扩展）
- 结算号（BKPF-XBLNR）、汇率（BKPF-KURSF）

## 透明表与用途

- 主数据与凭证：`FAGLFLEXA`、`BKPF`、`BSEG`
- 公司/组织扩展：`ZSAP_BUKRS`
- 科目与组织文本：`SKAT`、`SKA1`、`CEPC`、`CEPCT`、`CSKT`
- 客商与物料：`KNA1`、`LFA1`、`MARA`、`MAKT`、`T023T`、`T077X`
- 资产：`ANLA`、`ANKT`
- 自定义配置/业务：`ZSAP_FI179`、`ZFI032_DOC`、`ZSAP_FI054`

## 规则与约束

- 借贷金额规则：
  - `DRCRK = 'S'` -> 借方金额 = `HSL`
  - `DRCRK = 'H'` -> 贷方金额 = `-HSL`
- 调整期判断：`POPER in (13,14,15,16)` 为“是”，其余“否”
- 业务类型：`BLART = 'Z4'` -> “期末调汇”，其余“手工录入”
